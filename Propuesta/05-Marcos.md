# Tecnologías a utilizar

El desarrollo de AgroSmart se basará en Python como lenguaje de programación central para la construcción de la lógica del sistema, mientras que Git y GitHub se utilizarán para la gestión del repositorio y el trabajo colaborativo.

## Lenguaje de programación

Se empleará Python por su sintaxis clara, legibilidad y versatilidad en la manipulación e implementación de estructuras de datos. Esta tecnología permitirá construir de forma modular las secciones correspondientes al registro de cultivos, control de riego, administración de inventario, calendario agrícola y estimación de cosechas.

## Git y GitHub

Para la gestión del código fuente se utilizará Git a nivel local, permitiendo el control de versiones, creación de ramas por funcionalidad y resolución de conflictos. Por su parte, GitHub funcionará como el repositorio centralizado en la nube para integrar los avances del equipo mediante solicitudes de extracción y mantener la documentación del proyecto organizada.

# Estructuras de datos

El sistema integrará arreglos dinámicos para almacenar de manera secuencial los registros de cultivos e historial de riego. Asimismo, se implementarán diccionarios para lograr búsquedas directas en el módulo de inventarios, colas tipo FIFO para programar las tareas del calendario de riego en orden cronológico y listas enlazadas para estructurar las fases de crecimiento de los cultivos.

# Algoritmos que se implementarán

Para la consulta y organización de la información se aplicarán algoritmos de búsqueda lineal y binaria que faciliten la localización rápida de cultivos o insumos. Del mismo modo, se utilizarán algoritmos de ordenamiento como Quicksort para clasificar cosechas e inventarios según su fecha o nivel de prioridad, combinados con algoritmos de estimación para predecir el rendimiento y consumo de recursos.

# Cronograma

El proyecto se desarrollará a lo largo de cinco semanas. La primera semana se destinará al análisis y diseño de requerimientos. Durante la segunda semana se construirá la base del sistema en Python. En la tercera semana se integrarán los algoritmos de búsqueda, ordenamiento y la lógica de riego. La cuarta semana abarcará las pruebas e integración del código, finalizando en la quinta semana con la elaboración de manuales y la entrega general.

# Conclusiones

La implementación de AgroSmart permitirá automatizar tareas agrícolas clave y reducir los errores derivados del control manual. Por otro lado, la adopción de Git y GitHub garantizará un flujo de trabajo colaborativo y ordenado durante la evolución del software, mientras que la integración de estructuras de datos y algoritmos asegurará un procesamiento de información ágil y escalable.
