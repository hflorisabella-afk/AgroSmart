# Descripción del sistema
El sistema es una plataforma informática desarrollada para facilitar la gestión y administración de actividades agrícolas dentro de una finca o explotación agrícola. Su propósito es ayudar al agricultor a llevar un control organizado de los cultivos, el riego, las actividades programadas, el inventario de insumos y la estimación de las cosechas.

A través de este sistema, el usuario podrá registrar información detallada de cada cultivo, programar tareas agrícolas, controlar el uso de recursos como agua y fertilizantes, administrar el inventario de herramientas e insumos y obtener reportes que le permitan tomar mejores decisiones para aumentar la productividad.
# Módulos del sistema
El sistema está dividido en varios módulos, cada uno encargado de una función específica para facilitar la administración de una finca agrícola. Esta estructura modular permite que el sistema sea más organizado, fácil de mantener y escalable para futuras mejoras.
## Registro de cultivos
Este módulo permite almacenar y administrar toda la información relacionada con los cultivos sembrados dentro de la finca. Su objetivo es mantener un historial actualizado de cada cultivo para facilitar su seguimiento durante todo su ciclo de vida.

Funciones principales
- Registrar nuevos cultivos.
- Editar o actualizar la información registrada.
- Eliminar registros que ya no sean necesarios.
- Registrar el nombre del cultivo.
- Registrar la variedad o especie.
- Registrar la fecha de siembra.
- Registrar la fecha estimada de cosecha.
- Registrar la ubicación o parcela donde fue sembrado.
- Registrar el estado actual del cultivo (sembrado, en crecimiento, listo para cosechar o cosechado).
- Consultar el historial de cultivos registrados.
