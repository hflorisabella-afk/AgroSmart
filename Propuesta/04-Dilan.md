# Descripción del sistema
El sistema es una aplicación diseñada para facilitar la administración de una finca o cultivo agrícola. Permite registrar información de los cultivos, controlar el riego, organizar las actividades agrícolas mediante un calendario, administrar el inventario de insumos y herramientas, además de generar predicciones de cosechas para apoyar la toma de decisiones.
