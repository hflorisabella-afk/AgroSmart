# Objetivos específicos
Buscar y ordenar datos rápidamente: Permitir que el agricultor busque cultivos por código o nombre y los ordene por fecha o cantidad sin demoras.

Construir un menú de texto claro: Diseñar un sistema por consola fácil de usar que reúna el registro de cultivos, el control de agua, el inventario y las fechas de cosecha.

# Alcance
Guardar datos completos de cada siembra, buscarlos al instante con su código y clasificarlos por tipo.

# Limitaciones
No se conectará a sensores físicos de humedad o clima. El usuario tendrá que escribir los datos.

# Beneficios del proyecto
Ayuda a no desperdiciar el recurso repartiéndolo donde realmente hace falta.
